🐟 MoyuCast · 摸鱼投屏

老板来了？一键消失。 Boss incoming? One key, and it's gone.

基于 scrcpy 3.3.4 的 Windows 图形化投屏控制台。不用记命令行，
把手机画面投到电脑上，还能用老板键一键隐身、调透明度、鼠标移开自动隐藏。

功能

🕵️ 一键隐身老板键隐藏 / 恢复投屏窗口，连窗口大小位置透明度都原样还原
👻 透明可调20% ~ 100% 实时调节，只作用于投屏窗口
🖱️ 鼠标移开自动隐藏离开窗口 0.5 秒自动进入隐身状态
📐 比例锁定无黑边、等比缩放，怎么拖都不变形
📶 无线投屏USB 连一次，自动切换为无线
🌙 息屏投屏手机亮度压到 0 并保持唤醒，电脑端照常操作
🔊 音频三态手机响 / 两边响 / 仅电脑响
🌏 中英双语默认跟随系统，应用内一键切换
📌 托盘常驻最小化到托盘，双击恢复
🔄 检查更新应用内读取 GitHub Releases，国内自动走镜像

快速开始

  • 手机打开「开发者选项 → USB 调试」，用数据线连电脑
  • 双击 MoyuCast.exe，选设备，点 开始投屏
  • 按 Ctrl + 随时隐身 / 恢复（可自定义）
